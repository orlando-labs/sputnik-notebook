# Sputnik Notebook 0.1.0 (2) — macOS

Подготовка выпуска: 5 ноября 2026 года. Sputnik language/VM: 1.0.0.

## Русский

Нативный Notebook для Apple Silicon (arm64). Эта сборка требует **macOS 26.0
или новее** из-за минимальных версий включённых библиотек.

В приложении находятся UI, отдельный worker, локальный remote helper, компилятор
Sputnik, библиотеки, SDK для native extensions и исходные хелперы `notebook.ui`.
Для запуска приложения и обычных книг Homebrew, Node.js и Python не нужны.
Сборка сторонних native extensions из исходников требует подходящего toolchain
(например, Xcode Command Line Tools); дополнительные требования определяет сама
зависимость. Внешние пакеты и датасеты не включены в приложение.

В этой подготовке выпуска:

- `notebook.ui` доступен без отдельной установки и зависимости в книге.
- Ошибки импорта указывают имя, исходный файл и строку; в UI есть переход к ней.
- Релиз собирается отдельно от рабочего приложения; сохраняются снимки исходников,
  ревизии, признаки незакоммиченных изменений и контрольные суммы компонентов.
- Проверяются архитектура, минимальная macOS, динамические зависимости,
  лицензии включённых библиотек и целостность подписи.

**Подпись: ad-hoc. Developer ID отсутствует. Нотарификация Apple не выполнена.**
Проверка целостности через `codesign` не означает одобрения Gatekeeper.
После загрузки macOS может заблокировать первый запуск. Для доверенного
приложения Apple описывает индивидуальное разрешение через System Settings →
Privacy & Security → Open Anyway после первой попытки открыть приложение:
[инструкция Apple](https://support.apple.com/102445).

Для установки откройте DMG и перетащите Sputnik Notebook в папку «Программы».
SHA-256 и исходники включённых библиотек Nettle и GMP доступны рядом с DMG.

## English

Native Notebook for Apple Silicon (arm64), requiring **macOS 26.0 or later**
because of the deployment targets of its bundled libraries. Sputnik language/VM:
1.0.0.

The app includes its UI, isolated worker, local remote helper, Sputnik compiler,
dynamic libraries, native extension SDK and `notebook.ui` source helpers. Running
the app and ordinary notebooks requires no Homebrew, Node.js or Python. Building
third-party native extensions from source needs an appropriate toolchain such as
Xcode Command Line Tools and any requirements of that dependency. External
packages and datasets are not bundled.

This preparation includes built-in `notebook.ui`, import errors linked to their
source line, separate release artifacts and source provenance, plus checks of
architecture, minimum OS, dynamic linkage, third-party notices and signature
integrity.

**Ad-hoc signed; no Developer ID; not notarized by Apple.** A valid `codesign`
integrity check does not imply Gatekeeper approval. macOS may block the first
launch after download. Apple documents the per-app Open Anyway option in
System Settings → Privacy & Security after attempting to open a trusted app:
[Apple instructions](https://support.apple.com/102445).

To install, open the DMG and drag Sputnik Notebook into Applications.
The SHA-256 checksum and source for the bundled Nettle and GMP libraries are
available alongside the DMG.
