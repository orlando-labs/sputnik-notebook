# Sputnik Notebook 0.1.0 (3) — macOS

Дата выпуска: 8 ноября 2026 года. Sputnik language/VM: 1.0.0.

## Русский

Нативный Notebook для Apple Silicon (arm64), **macOS 26.0 и новее**.

- **Check Module** заменяет Run Module. Кнопка и ⌘Return проверяют синтаксис,
  импорты и компилируемость текущего черновика без выполнения кода, загрузки
  native-библиотек и runtime-грантов. Проверка не сохраняет черновик и не
  добавляет запись в историю запусков.
- Ошибки модуля, полученные при запуске листа или доски, видны на странице
  модуля. Доска показывает причину остановки, а список страниц — индикатор
  ошибки. Ссылка открывает модуль, прокручивает исходник и выделяет место
  ошибки. Координаты старой версии не применяются к изменённому черновику.
- Enter сохраняет отступ и добавляет уровень после начала блока или внутри
  скобок. Двоеточия и скобки в строках и комментариях не меняют отступ.
  Undo/Redo сохраняют ввод новой строки как одну операцию.

В приложении находятся UI, отдельный worker, локальный remote helper,
компилятор Sputnik, библиотеки, SDK для native extensions и исходные хелперы
`notebook.ui`. Для приложения и обычных книг Homebrew, Node.js и Python не нужны.
Сборка сторонних native extensions из исходников требует подходящего toolchain
и дополнительных зависимостей, указанных их авторами. Пакеты и датасеты не
включены в приложение.

**Подпись: ad-hoc. Developer ID отсутствует. Нотарификация Apple не выполнена.**
Проверка целостности через `codesign` не означает одобрения Gatekeeper.
Если macOS блокирует первый запуск доверенного приложения, используйте
System Settings → Privacy & Security → Open Anyway после попытки открыть его:
[инструкция Apple](https://support.apple.com/102445).

Откройте DMG и перетащите Sputnik Notebook в папку «Программы». SHA-256 и
исходники включённых библиотек Nettle и GMP доступны рядом с DMG.

## English

Native Notebook for Apple Silicon (arm64), requiring **macOS 26.0 or later**.
Release date: November 8, 2026. Sputnik language/VM: 1.0.0.

- **Check Module** replaces Run Module. The button and ⌘Return check the current
  draft's syntax, imports and compilation without executing code, loading native
  libraries, or requiring runtime grants. Checks neither save the draft nor add
  an entry to run history.
- Module errors from sheet and board runs also appear on the module page.
  Boards show why a run stopped, and page lists indicate errors. Error links
  open the module, scroll to the source and select the relevant range. Locations
  from an older source version are not applied to an edited draft.
- Enter preserves indentation and adds a level for blocks and bracket
  continuations. Colons and brackets in strings and comments do not affect
  indentation. Undo/Redo treat each indented newline as one edit.

The app bundles its UI, isolated worker, local remote helper, Sputnik compiler,
libraries, native extension SDK and `notebook.ui` source helpers. Running the app
and ordinary notebooks requires no Homebrew, Node.js or Python. Building external
native extensions from source needs a suitable toolchain and their declared
dependencies. Packages and datasets are not bundled.

**Ad-hoc signed; no Developer ID; not notarized by Apple.** A valid `codesign`
integrity check does not imply Gatekeeper approval. For a trusted app blocked on
first launch, Apple documents the per-app Open Anyway option in System Settings
→ Privacy & Security: [Apple instructions](https://support.apple.com/102445).

Open the DMG and drag Sputnik Notebook into Applications. The SHA-256 checksum
and source for the bundled Nettle and GMP libraries are available alongside it.
