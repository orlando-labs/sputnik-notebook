# Sputnik Notebook 0.3.0 — macOS

## Русский

Выпуск для Apple Silicon (arm64) и macOS 26.0 или новее. В комплект входит
Sputnik 1.0.0.

- Ячейки могут экспортировать значения для других листов. Окно Exports
  предлагает имена из кода ячейки и позволяет выбрать несколько переменных.
  Импорты настраиваются на уровне листа и обновляются через Watch.
- Циклическая связь между листами отображается явно. После полного прохода
  Notebook показывает, что ячейка готова к следующей ручной итерации.
- В примере Autoencoder Showcase отдельный лист генерирует датасет, который
  импортирует лист обучения.
- Доску можно открыть в отдельном окне.

Откройте DMG и перетащите Sputnik Notebook в папку «Программы». Образ содержит
приложение с подписью ad-hoc. [Открытие приложения на Mac](https://support.apple.com/102445)

## English

For Apple Silicon (arm64) and macOS 26.0 or later. Includes Sputnik 1.0.0.

- Cells can export values to other sheets. The Exports dialog suggests names
  from the cell source and supports selecting multiple variables. Sheets own
  their imports, which update through Watch.
- Notebook displays cross-sheet cycles and shows when a cell is ready for
  another manual iteration after a full pass.
- In Autoencoder Showcase, a dedicated sheet generates the dataset and the
  training sheet imports it.
- Open a board in a separate window.

Open the DMG and drag Sputnik Notebook into Applications. The image contains
an ad-hoc signed app. [Open an app on Mac](https://support.apple.com/102445)
