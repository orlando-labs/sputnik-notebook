# Sputnik Notebook 0.3.1 — macOS

## Русский

Выпуск для Apple Silicon (arm64) и macOS 26.0 или новее. В комплект входит
Sputnik 1.0.0.

- Компоненты и встраиваемые доски установленных пакетов появляются на цветных
  вкладках палитры. Свойства экземпляров доступны в Object Inspector.
- Пакет `slowpilot/orbit-notebook` добавляет локальный HTTP Server и доску с
  отдельным контроллером и входами. Установите его из Dependencies. Если в книге
  уже установлен Orbit с обновлённым манифестом, Notebook предложит этот пакет.
- Просмотрщик графиков поддерживает миллиметровую сетку и настройки типографики.

Откройте DMG и перетащите Sputnik Notebook в папку «Программы». Образ содержит
приложение с подписью ad-hoc. [Открытие приложения на Mac](https://support.apple.com/102445)

## English

For Apple Silicon (arm64) and macOS 26.0 or later. Includes Sputnik 1.0.0.

- Installed packages contribute components and embedded boards to colored tabs
  in the component palette. Configure each instance in the Object Inspector.
- Install `slowpilot/orbit-notebook` from Dependencies for a local HTTP Server
  and an embedded board with its own controller and inputs. An installed Orbit
  package with the updated manifest suggests this companion.
- The plot viewer supports graph paper and typography settings.

Open the DMG and drag Sputnik Notebook into Applications. The image contains
an ad-hoc signed app. [Open an app on Mac](https://support.apple.com/102445)
